Overview

Market Mood is a Reddit-sentiment dashboard for stock tickers, built in 36 hours at HackMIT 2024 by a 4-person team. The team wired together the Reddit API for ingest of recent posts and comments mentioning a given ticker, the OpenAI API for sentiment scoring on each post, and a React frontend for the dashboard view that aggregates the scores into a per-ticker mood signal.

My role: Hackathon team project (4-person team). I built parts of the Reddit sentiment-ingestion pipeline and the OpenAI sentiment-scoring loop during HackMIT 2024 — specifically the ticker-keyed Reddit query layer and the batched scoring calls that feed the dashboard.

What we built

The pipeline starts from a user-supplied ticker symbol. Our team's Reddit ingestion layer pulls the most recent N posts and top-level comments from a curated set of investing subreddits matching that ticker. Each item is sent through the OpenAI API with a sentiment-scoring prompt that returns a normalized score in [–1, +1]. The React dashboard aggregates those scores by time-window and renders a per-ticker mood line plus the underlying source posts so users can verify the signal isn't being driven by a handful of outliers.

Code, README, and run instructions are open source on GitHub at the link above. The project was built as a hackathon submission rather than a production service, so rate-limit handling and persistence are deliberately minimal.
